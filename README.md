# ACG — AI Color Grading

카메라로 찍은 고화질 사진을 버튼 한 번으로 전문가처럼, 화질 손실 없이 색보정하는 앱입니다.
윈도우 PC를 먼저 만들고 안드로이드로 배포합니다.

## 구조

| 폴더 | 내용 |
|---|---|
| `engine/` | Rust 이미지 엔진 (윈도우·안드로이드 공용). 보정 파이프라인, 입출력, 템플릿, 자동 분석, 참조 사진 매칭 |
| `app/` | Flutter UI (예정) |

## 설계 원칙

- **AI와 자동 보정은 픽셀이 아니라 '레시피'(보정값)를 만든다.** 슬라이더 값, 톤커브, 3D LUT로 이루어진 JSON이라
  원본 해상도에 그대로 적용되고, 결과를 슬라이더로 다시 조정할 수 있습니다.
- 원본은 수정하지 않습니다(비파괴 편집).
- 내부 처리는 32비트 부동소수점, 내보내기는 16비트 TIFF/PNG(무손실) 또는 품질 100 JPEG(디더링으로 밴딩 방지).

## 엔진 사용해 보기 (CLI)

Rust 설치 후 `engine/` 폴더에서:

```
cargo build --release
target/release/grade presets 사진.jpg 결과폴더        # 템플릿 전부 적용
target/release/grade auto    사진.jpg 결과폴더        # 사진 분석 → 자동 보정 + 스타일 후보
target/release/grade apply   사진.jpg 필름 결과.tif    # 템플릿 하나 적용 (16비트 TIFF)
target/release/grade match   사진.jpg 참조사진.jpg 결과.png 0.8   # 참조 사진 스타일 따라하기 (+ .cube LUT 저장)
```

기본 템플릿: 자연스럽게, 선명하게, 필름, 시네마틱, 따뜻한 감성, 차가운 무드, 인물 화사하게, 풍경 강조,
야경 네온, 흑백 클래식, 흑백 하이콘트라스트, 적외선, 플래시, 파스텔 매트.

## 로드맵

1. 엔진 (완료): 보정 파이프라인, 템플릿, 자동 분석 후보, 참조 매칭
2. Flutter 윈도우 앱: 라이트룸 모바일 스타일 편집 화면
3. AI 보정: Claude / Gemini / ChatGPT 중 선택 + 본인 API 키. 자연어 요청("적외선처럼")과 보정 가이드 링크를 레시피로 변환
4. RAW 지원, 마스킹(피사체·하늘), 일괄 처리
5. 안드로이드 빌드·배포
